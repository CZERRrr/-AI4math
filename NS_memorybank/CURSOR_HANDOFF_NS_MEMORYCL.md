## 1. 用户希望研究什么

研究属于 **AI for PDE 中的时变 PDE 神经算子预测、记忆辅助误差修正和跨工况持续适应**。

保留两个核心部分：

1. **Memory bank**：在自回归滚动预测中检索相关训练经验，学习如何修正每一步预测，研究能否降低误差累积。
2. **Continual learning，CL**：出现新物理条件后，使用新条件数据更新预测器，同时回放有限旧任务样本，研究适应新条件与保留旧能力之间的平衡。

用户不希望把项目直接改成纯 CL，也不希望记忆库一直只是训练完成后手动附加的固定修正。当前第一版升级方案是：**让修正模块参与多步滚动训练；跨任务更新 FFNO 后刷新记忆残差。**

FFNO 暂时作为主干。当前不转向 Transformer、foundation model、全连接 PINN 或 Mamba，也不把“少数据”作为未经实验支持的主结论。

研究假设尚未被 NS 实验验证：

- 学习如何使用检索残差，是否优于固定相似度加权？
- 多步修正训练是否有利于长滚动预测？
- 主干更新后，刷新记忆库是否比复用旧残差更可靠？
- 有限旧样本回放是否降低旧任务性能下降，同时保持新任务预测能力？

这些是待验证问题，不是已经证明的创新点。方法的新颖性需要另外核查相关工作。

## 8. 最终实验框架：三个环节

### 8.1 环节一：每一步预测与记忆修正

定义：

- $x_t$：真实物理状态；当前 NS 计划为 $[v_x,v_y,c]$，以实际字段为准。
- $\widehat{x}_t$：预测状态。
- $X_t$：模型输入，可以是当前状态，也可以是后续扩展的短历史。
- $\mu$：工况信息，例如黏性系数、外力或边界条件。
- $F_\theta$：条件 FFNO。
- $\Phi$：构造 query/key 的特征函数。
- $\mathcal B$：仅含训练样本的记忆库。
- $C_\phi$：可训练的修正模块。

**FFNO 分支与 query 分支使用同一当前状态。** 两条输入的区别是用途：一个做动力学预测，另一个把状态编码成用于检索的描述，不是两套额外真值。

训练集逐通道标准化：

$$
z_t=\frac{x_t-m_{train}}{s_{train}}.
$$

原始训练经验应保留足以重建残差的信息：

$$
\mathcal B_{raw}=\{(z_i,\mu_i,z_{i+1},\mathrm{trajectoryID}_i)\}.
$$

必要时保留真实未来短片段以支持多步训练/回放。归一化参数、force、时间间隔和来源 ID 也要保存。

由当前主干生成派生缓存：

$$
k_i=\Phi(z_i,\mu_i),\qquad
r_i=z_{i+1}-F_\theta(z_i,\mu_i).
$$

当前 query：

$$
q_t=\Phi(\widehat z_t,\mu).
$$

检索相似候选：

$$
\mathcal I_t=\operatorname{TopK}_i\;\mathrm{sim}(q_t,k_i).
$$

第一版可用固定特征：小尺度空间池化、低频幅值谱、逐通道统计、外力描述和已知物理参数；query 与 key 必须使用相同特征顺序和标准化。
key/query 的标准化统计只能从 bank 训练样本拟合。

可训练小 MLP 给候选评分，并加一个 **残差恒为零的候选**：

$$
(a_{t,0},\ldots,a_{t,K})
=\operatorname{softmax}(g_\phi(q_t,k_i,r_i)),\qquad r_0=0.
$$

最终预测：

$$
\widehat z_{t+1}
=F_\theta(\widehat z_t,\mu)
+\gamma\sum_{i\in\mathcal I_t}a_{t,i}r_i.
$$

- $K$ 是候选数量；3 只是初始设置，不是 NS 上已经验证最优。
- $a_{t,i}$ 是学习出的候选权重。
- 零候选让模块学习降低修正；softmax 权重一般不会严格变成 0 或 1。
- $\gamma$ 是全局修正强度，在验证集选择，必须包含 $\gamma=0$。
- $\gamma=0$ 应严格恢复同一个 FFNO 的预测。
- 初始版不沿用 SWE 中未经调参验证的 0.2 硬阈值。
- 修正后的预测继续作为下一步输入；不会每一步重新喂入真实未来状态。

### 8.2 环节二：用多步预测训练修正模块

第一版采用分阶段训练：

1. 用训练轨迹训练 FFNO，基于验证 rollout 选择主干 checkpoint。
2. 固定该 FFNO，构建训练残差库。
3. 从训练轨迹选起点，自回归连续预测 $H$ 步，每一步都进行检索与修正。
4. 比较修正后的预测与真实后续轨迹，更新修正模块参数 $\phi$。

$$
\mathcal L_{corr}(\phi)=
\frac1H\sum_{j=1}^{H}
\operatorname{MSE}(\widehat z_{t+j},z_{t+j}).
$$

初始 $H=3$ 用于跑通，后续比较 1、3、5 等，并考虑训练开销。

必须保证：

- 冻结 FFNO 参数不等于把每一步 FFNO 调用包进 `torch.no_grad()`。
- 修正后的状态进入下一步 FFNO；必须保留对其输入的梯度，才能训练前面步骤的修正。
- 离散 Top-K 索引本身通常不可微；本阶段学习候选融合，不假称所有检索步骤都端到端可微。
- 修正模块训练期间，排除当前 query 所属整条轨迹的 bank 条目，避免检索到自己及相邻帧造成虚高收益。
- 需要多个独立训练轨迹；若排除后候选不足，降低 K 或增加轨迹，不可静默撤销排除。
- 测试时不更新参数、不写入真值，也不把模型预测当作新真值存库。

这已经让记忆修正参与训练，但尚不等同于主干、可学习 key 编码器、记忆全部联合训练，也不等同于 MemNO 的序列隐状态记忆。

### 8.3 环节三：新工况后的 CL 更新

只有在物理条件或分布变化有明确依据时才定义 task B，例如黏性系数、外力统计或边界条件改变。
换一个文件名、换一批初值，不能自动证明是不同工况。

新任务到来后：

1. 从上阶段主干 checkpoint 开始。
2. 用新任务训练数据与有限旧样本回放更新 FFNO。
3. 根据更新后的 FFNO，重新计算允许保留样本的残差缓存。
4. 固定更新后的 FFNO，重新训练或适应修正模块。
5. 在已见任务验证集选择设置，在已见任务测试集统一评估。

$$
\mathcal L_{adapt}(\theta)
=\mathcal L_{new}(\theta)
+\lambda\mathcal L_{replay}(\theta).
$$

回放样本与新样本在 batch 中的比例也决定有效权重，需要记录。

关键一致性：

$$
r_i^{old}=z_{i+1}-F_{\theta_{old}}(z_i,\mu_i)
$$

一般不能作为新主干的有效残差，更新后应计算：

$$
r_i^{new}=z_{i+1}-F_{\theta_{new}}(z_i,\mu_i).
$$

**残差必须刷新。** 如果 key 使用固定特征、输入与标准化没有改变，key 不一定因主干更新而改变；如果编码器、特征或标准化变化，则必须刷新 key，并保持 query/key 同版本。
流程图“重新计算 key 和残差”是保守实现方式，不代表固定 key 必然发生数值变化。

回放与检索是两种用途：

- 原始旧训练经验：供 CL 更新和重新生成残差。
- 派生 key/residual 缓存：供预测时检索修正。

可共用来源数据，但要分别管理原始样本预算和派生库容量。
每阶段记录 checkpoint hash、key/归一化版本、原始样本 ID、bank 条目数和磁盘占用。

### 阶段 1：先跑 NS FFNO baseline

沿用用户的 `ffno_core`，改数据读取、输入输出通道、逐通道归一化与报告。

若数据包含计划的三状态分量，初始模型输入为：

$$
[v_x,v_y,c,f_x,f_y,x,y,\nu]\longrightarrow [v_x',v_y',c'].
$$

若黏性系数未知且只有单条件，可以暂不输入该参数；如果为了固定接口以零占位，必须在元数据标为未知，不把零当物理黏性系数。

原 `FNOFactorized2DBlock` 的输出头为一通道，应适配三通道。
保持原频谱层逻辑，包括 non-fork 分支原来的 `out(b)`，不要无意间重写成另一种 FFNO 后仍宣称完全相同。
原 300,033 参数量不再自动适用，必须重新统计。

### 阶段 2：固定 bank 与可训练修正对照

至少对比：

| 编号 | 方法 | 作用 |
|---|---|---|
| B0 | FFNO，单步训练 | 主基线 |
| B1 | B0 + 固定相似度残差融合 | 检索经验本身的作用 |
| B2 | B0 + 单步训练修正模块 | 学习候选融合的作用 |
| B3 | B0 + 多步训练修正模块 | 与滚动目标对齐的作用 |
| B4 | FFNO-only 多步微调，匹配额外预算 | 区分记忆收益与额外训练收益 |

最小跑通版可先做 B0、B1、B3，但正式归因需要补 B2、B4。
B0/B1/B2/B3 使用同一个冻结主干、相同测试轨迹和预测范围。
B4 是独立训练控制，需要明确其主干发生变化。

### 阶段 3：两任务 CL 对照

在真实 task B 具备后，从相同 task-A checkpoint 分支：

| 方法 | 新任务更新 | 旧任务回放 | 检索修正 |
|---|---|---|---|
| C0 | 不更新 | 无 | 无，用于衡量分布变化 |
| C1 | 直接微调 | 无 | 无 |
| C2 | 微调 | 有 | 无 |
| C3 | 微调 | 无 | 有，明确库保留策略 |
| C4 | 微调 | 有 | 有，刷新 residual |

最小实现可以先跑 C1/C2 的主干对照和对应的检索修正结果，但不能据此完成所有机制归因。
保持更新次数、batch size 和评估任务一致；同时记录新旧样本各自曝光量，等更新次数不代表等新数据量。
初始回放可用固定少量旧轨迹，后续比较固定窗口/样本预算。
派生 residual bank 总容量固定，不能随任务数无上限增长。

### 阶段 4：正式规模与消融

只有流程和指标正确后再增大训练预算：

- 至少 3 个 seed，按测试轨迹计算配对误差差异及不确定性。
- 比较 k、bank 大小、query 特征、零候选、多步 H 和修正强度。
- 比较 stale residual 与 refreshed residual。
- 检查回放预算与任务顺序。
- 比较更长物理预测范围，前提是存在相应真值。
- 与普通 recurrent/history 模型的比较可列为后续，不要第一轮同时扩展所有结构。

## 12. 评价指标与解释边界

### 12.1 滚动预测

$$
e_{i,j}=\frac{\|\widehat x_{i,j}-x_{i,j}\|_2}{\max(\|x_{i,j}\|_2,\varepsilon)}.
$$

保存：

- 每个预测步的轨迹平均 Relative L2。
- 轨迹与预测步双重平均的 rollout L2。
- 最后一步 L2、后段时间窗口 L2。
- 原始尺度 MSE。
- 三个物理通道分别的误差；额外报告速度向量的误差。

**混合速度与标量的 joint raw L2 可能被幅值较大的标量主导。**
不能只报一个总数就声称速度预测改善。接近零的目标范数也会导致相对误差敏感，应同时查看绝对误差与分通道统计。

“100 步自回归”是明确的评估协议；是否属于长时间物理演化，要结合真实 t、流动特征时间和训练窗口判断。
默认取文件前 101 帧可能只覆盖早期短时间，不能直接称为训练时间之外的长期外推。

### 12.2 持续学习

记录阶段 j 后任务 i 的误差表 $E_{i,j}$，同时报告旧任务与新任务。
两任务最简单的旧性能变化为：

$$
\Delta E_{old}=E_{A,after\ B}-E_{A,after\ A}.
$$

正值表示旧任务误差增加；它是误差变化量，不要混用分类准确率版本的 BWT 符号。
若使用标准遗忘指标，应在报告中单独定义。

同时报告适应更新次数、样本曝光量、训练时长、memory 刷新成本、推理时长、显存与磁盘占用。

### 12.3 物理诊断

可在数据边界、网格与物理变量确认后加入：速度散度、边界误差、能谱、涡量等。
当前原型没有压力投影或严格不可压约束，不要声称修正后保证满足 NS。
FFT 特征或 FFNO 架构也不代表数据一定是周期边界。

## 14. 必须避免的错误

1. 把旧 SWE 数据读取器直接用于 NS，或将 NS 第一个通道当水深。
2. 把同一轨迹的相邻帧随机拆成 train/valid/test 后声称跨轨迹泛化。
3. bank 中混入 valid/test 真值，或用测试结果反复选择 K/gamma。
4. query 训练时检索自己、同轨迹近邻作为主要“记忆收益”。
5. 主干已更新，却复用旧 checkpoint 的 residual。
6. query/key 的特征定义、标准化或版本不一致。
7. 错用 no_grad 切断跨步修正训练的梯度。
8. 假定更多预测步就自动等于更长物理时间或有可评估真值。
9. 把单条件 shard 当成已定义多个新工况。
10. 把已有固定库检索等同于已完成持续学习。
11. 把“固定 FFNO + 训练 router”写成“整个 FFNO 和记忆系统完全联合训练”。
12. 把平均 gate 数值写成修正触发比例。
13. 声称当前组合已经具有论文新颖性或必然优于 baseline。
14. 根据历史聊天中的文件路径声称已连接/修改了用户服务器；必须以实际访问能力为准。

## 15. 相关方法的借鉴边界

- **MemNO**：借鉴“历史/记忆对时变 PDE 的有效性”这一动机。其序列潜在记忆与这里的显式训练样本检索库不同，当前不是 MemNO 复现。
- **CL-PINN**：借鉴新任务学习时保留旧任务训练信息、通过回放缓解遗忘的思想。当前 FFNO 数据驱动训练并不是直接移植其全连接网络、物理损失或声称复现完整论文。
- **MemoryBank 类方法**：借鉴外部记忆、检索和更新管理思想。LLM 记忆管理与 PDE 全场残差修正不是同一个算法。
- 此前还讨论过检索残差预测、零修正候选等相关工作。若准备正式引用，应重新核查准确论文题目、作者、版本与算法，不将聊天里未核实的书目信息直接写入论文。

理论动机可讨论 Mori–Zwanzig：投影/部分观测动力学可能依赖历史。
但该理论不自动证明本项目的跨训练样本残差检索是精确记忆核，也不保证误差随时间必然降低。
检索跨样本经验和保存单轨迹历史是两种不同记忆，需要分别定义与实验。
